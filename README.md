# Sovereign Vault：士業・中小企業向け ランサムウェア特化型データ防衛インフラ

## 【課題】データの消失は、事業の停止に直結します
顧客の機密情報や財務データが、ある日突然ランサムウェアで暗号化され、開けなくなってしまったら。あるいは、予期せぬトラブルでデータが消去されてしまったら。
専任のセキュリティ担当者がいない小規模な事務所や企業にとって、データインシデントはそのまま「事業の停止」と「信用の失墜」を意味します。

## Sovereign Vaultの役割
Sovereign Vault（ソブリン・ヴォルト）は、そうした致命的なデータ消失リスクから事業を守るための、堅牢なクラウドストレージ環境です。

複雑なITの知識は必要ありません。最新のAWS（Amazon Web Services）アーキテクチャを活用し、「万が一攻撃を受けても、絶対にデータが消えない・改ざんされない」仕組みを、貴社の環境に最短即日で構築します。

## 実現する3つの防衛機能
当システムは、表面的なウイルス対策ソフトではなく、インフラ（基盤）レベルでの防衛を提供します。

* **1. 物理的な「上書き・削除」の完全ブロック**
  * AWS S3 Object Lock機能により、保存されたデータは指定期間（最長10年等）、誰であっても削除や上書きができない「読み取り専用」の状態になります。悪意のあるハッカーはもちろん、社内の管理者ミスによるデータ消失も防ぎます。
* **2. 暗号鍵の強固な保護**
  * データを人質に取るランサムウェアの手口に対抗するため、暗号鍵の権限管理（AWS KMS）を厳格化し、システム外部からの鍵の破壊を無効化します。
* **3. 改ざん不可能な操作ログ（証拠保全）**
  * 「誰が・いつ・どのデータに触れたか」を記録する監査ログ（AWS CloudTrail）を自動生成します。ログ自体も保護されるため、有事の際の法的コンプライアンス要件も満たします。

## コア・セキュリティ・アーキテクチャ

### 1. 絶対不変ストレージ (Immutable Storage by WORM)
* **S3 Object Lock (COMPLIANCE Mode):** データの保存期間を3650日間（10年間）にハードコード。この設定は、AWSルートアカウント、およびAWSサポートチームであっても変更・削除・短縮は不可能です。
* **暗号シュレッディング対策 (Anti-Crypto-Shredding):** KMSカスタマーマネージドキー（CMK）において、キーの無効化（`DisableKey`）および削除スケジューリング（`ScheduleKeyDeletion`）をIAMポリシーの明示的拒否（Deny）により完全ブロック。データの暗号鍵を破壊して実質的に読み取り不能にする攻撃を未然に防ぎます。

### 2. データ完全性と防御ライン (Data Integrity & Perimeter Defense)
* **TLS 1.2/1.3の強制:** プレーンなHTTP通信によるデータ転送をS3バケットポリシーで明示的に拒否。
* **ポリシー改ざん防止:** バケットポリシー自体の削除・変更操作（`DeleteBucketPolicy` / `PutBucketPolicy`）を拒否し、設定のドリフト（乖離）やバックドアの作成を防止。
* **デフォルト暗号化の強制:** 全てのオブジェクトに対し、AWS KMSを用いたサーバーサイド暗号化（SSE-KMS）を強制。

### 3. 不可逆な監査ログ (Immutable Audit Trails)
* **AWS CloudTrailによるデータ監視:** S3バケットに対するすべてのデータ操作（Read/Write/Deleteイベント）を、完全に独立したログ専用バケット（`log_bucket`）へリアルタイムに転送。
* **ログファイル検証の有効化:** ログが転送後に改ざんされていないかを暗号学的に検証する機能を有効化（`enable_log_file_validation = true`）。
